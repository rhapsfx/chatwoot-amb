KEY CONCEPTS:
=============

1. Node Reference Syntax
   ----------------------
   $("Node Name").item.json.fieldName
   
   This allows any node to access data from any upstream node,
   bypassing intermediate nodes completely.

2. Why This Fix Works
   -------------------
   - Does NOT rely on IF node to pass data
   - Directly accesses source node output
   - Guaranteed availability if source node executed
   - More explicit and debuggable

3. Data Flow
   ----------
   Old way: Parse → IF → Update (broken chain)
   New way: Parse → IF (condition only)
           Parse → Update (direct data reference)

4. Best Practice
   -------------
   Use node references when:
   - Data passes through branching nodes (IF, Switch)
   - Need to access non-immediate upstream data
   - Debugging data availability issues
   
   Use $json when:
   - Simple linear flow
   - Immediate upstream node
   - No branching logic
