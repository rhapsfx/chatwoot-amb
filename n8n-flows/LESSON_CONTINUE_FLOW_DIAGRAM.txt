PYTHON VS N8N COMPARISON
==============================================

Python Function AHF2 (Lines 1111-1118):
  • Sends lesson intro message
  • Checks userStatus for stop
  • Calls AHF3 if not stopped
  ✓ n8n: Message sent, no stop check (user can't stop in n8n yet)

Python Function AHF3 (Lines 1119-1128):
  • Checks getIntent for "Traveling" vs local
  • Sends different messages based on intent
  • Sets lastMessage to "AHG1"
  ⚠ n8n: Generic message only (no intent check yet)

Python Function AHG1 (Lines 1130-1166):
  • Parses zipcode OR Apple Maps link
  • Geocodes using findGlobalGeocode
  • Handles multiple results with geocode list picker
  • Calls findStores for spatial search
  • Sends store list picker OR time picker
  ⚠ n8n: Simplified - validates text, directly to time picker

Python Function AHH2 (Lines 1191-1199):
  • Sends confirmation message
  • Sends continue question
  • Sends continue quick reply
  • Sets lastMessage to "AHI1"
  ✓ n8n: All 3 messages sent via separate nodes

Python Function AHI1 (Lines 1201-1217):
  • Checks selection: 1=skip, 0=continue
  • If skip: jump to AHK1 with learn more QR
  • If continue: send "so much more" message
  • Calls AHI2 (Rich Links)
  ✓ n8n: Logic inverted (Yes=continue, No=skip) but functionally equivalent
