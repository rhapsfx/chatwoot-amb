## Custom Node Credentials

**Required**: `chatwootBotApi` credential

**Configuration**:
1. In n8n → Credentials → Add Credential
2. Search for "Chatwoot Bot API"
3. Enter:
   - **Chatwoot URL**: `https://app.chatwoot.com` (or your instance)
   - **API Access Token**: From Chatwoot → Settings → Agent Bots → Your Bot

**Used By**:
- AMB Main Menu
- AMB Guitar List
- AMB AR Prompt
- AMB Apple Pay Request
- AMB Time Picker
- AMB Features Summary

## HTTP Header Auth Setup

**Required**: `httpHeaderAuth` credential

**Configuration**:
1. In n8n → Credentials → Add Credential
2. Select "Header Auth"
3. Enter:
   - **Name**: `api_access_token` (or as per Chatwoot API)
   - **Value**: Your Chatwoot Bot API token

**Used By**:
- Welcome Message 1 & 2
- Confirm Appointment
- Location Request

**Note**: Assign this credential manually after importing the workflow to these HTTP Request nodes.

## Common Issues

### "Node type not found"
**Cause**: Custom nodes not installed
**Solution**: Install nodes locally from `n8n-nodes-chatwoot-amb` directory

### "Credential not assigned"
**Cause**: HTTP Request nodes missing credentials after import
**Solution**: Manually assign `httpHeaderAuth` to each HTTP Request node

### "Template not found"
**Cause**: Template IDs don't match your Chatwoot instance
**Solution**: Update `templateId` parameter in each AMB node to your template IDs
