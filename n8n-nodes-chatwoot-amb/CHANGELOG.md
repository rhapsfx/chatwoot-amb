# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-15

### Added

- Initial release of n8n-nodes-chatwoot-amb
- **Chatwoot AMB List Picker** node for interactive lists with images
- **Chatwoot AMB Time Picker** node for appointment scheduling
- **Chatwoot AMB Quick Reply** node for quick action buttons
- **Chatwoot AMB Form** node for multi-field data collection
- **Chatwoot AMB Apple Pay** node for payment requests
- **Chatwoot AMB Rich Link** node for web links with previews
- **Chatwoot Bot API** credential type
- Comprehensive documentation and examples
- Error handling and validation
- TypeScript type definitions

### Features

- Support for all Apple Messages for Business rich message types
- Image support with base64 encoding
- Multi-page form support
- Dynamic time slot generation
- Payment network selection for Apple Pay
- Customizable received and reply messages
- Expression support for dynamic values
- Continue on fail option for error handling
