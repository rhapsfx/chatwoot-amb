## Design Notes

### Pattern Chosen
- **Controller Action**: Standard Rails RESTful pattern with member route
- **Data Flow**: Backend creates new bot → Returns with access token → Frontend displays in modal

### Duplication Logic

**What is Copied**:
- Bot name (with " (Copy)" suffix)
- Bot description
- Bot type (webhook / apple_messages_for_business)
- Outgoing URL
- Bot configuration JSON (`bot_config`)
- Avatar file (if attached)

**What is NOT Copied** (as per requirements):
- Inbox associations (user assigns manually)
- Version history (fresh start for AMB bots)
- Access token (new token generated automatically)

### Avatar Handling
```ruby
if @source_bot.avatar.attached?
  @agent_bot.avatar.attach(
    io: @source_bot.avatar.download,
    filename: @source_bot.avatar.filename,
    content_type: @source_bot.avatar.content_type
  )
end
```

### Security Guards
- Uses `Current.account.agent_bots.find(params[:id])` to ensure bot belongs to account
- Inherits authorization checks from `AgentBotsController#check_authorization`
- Access token is auto-generated by `AccessTokenable` concern

## Frontend User Flow

1. User clicks "Duplicate Bot" button (copy icon) in bot list
2. Backend creates duplicate with new access token
3. Frontend receives duplicated bot data
4. Modal opens in EDIT mode showing duplicated bot details
5. Access token is displayed (similar to create flow)
6. User can copy access token or close modal
7. Duplicated bot appears in bot list with name "{Original Name} (Copy)"

- **Average response time**: ~50-100ms (single database insert + avatar copy if applicable)
- **Database impact**: 1 INSERT into `agent_bots` table + 1 INSERT into `access_tokens` table

## Edge Cases Handled

1. **Missing source bot**: Returns 404 via `Current.account.agent_bots.find(params[:id])`
2. **Bot without avatar**: Safely skips avatar copy with `if @source_bot.avatar.attached?`
3. **Deep nested bot_config**: Uses `deep_dup` to prevent reference sharing
4. **System bots**: Duplicate button hidden for system bots in UI (line 233 of Index.vue)
